# Ürün Gereksinimleri Dokümanı — Sayac Uygulaması

## 1. Genel Bakış

Bu proje, kullanıcıların artış, azalış ve sıfırlama işlemleri yapabileceği interaktif bir sayaç uygulamasıdır. Uygulama React 18 + Vite + TypeScript + Tailwind CSS ile geliştirilmektedir. Türkçe arayüz ile son 10 değişiklik geçmişi timestamp ile kaydedilir. Karanlık/açık tema desteği mevcuttur. Hedef kitle: günlük kullanım yapan bireysel kullanıcılar, öğrenciler ve profesyoneller.

## 2. Hedefler

- Kullanıcının sayacı artırıp azaltarak sayısal değeri kontrol etmesini sağlamak
- Son 10 değişikliği timestamp ile birlikte geçmiş listesinde göstermek
- Karanlık ve açık tema arasında geçiş yapabilmek
- Mobil ve masaüstü cihazlarda sorunsuz çalışmak
- 2 saniyeden kısa ilk yükleme süresi sağlamak
- WCAG 2.1 AA erişilebilirlik standartlarına uymak

## 3. Tech Stack Detayı

- **Framework:** React 18.3.1 (function component + hooks)
- **Build:** Vite 5.x (hızlı geliştirme ve üretim build)
- **Styling:** Tailwind CSS 3.x (custom theme ile)
- **State:** React useState + useReducer (local state, üstten aktarım)
- **Storage:** localStorage (geçmiş verisi kalıcılığı için)
- **Routing:** Yok (tek sayfa uygulaması)
- **Language:** TypeScript 5.x (strict mode)

## 4. Fonksiyonel Gereksinimler

### 4.1 Sayac Görüntüleme
- Mevcut sayaç değeri ekranın ortasında büyük font ile gösterilir
- Sayısal değer 0-999999 arasında sınırlıdır
- Negatif değerler desteklenir
- Değer değiştiğinde animasyonlu geçiş uygulanır

### 4.2 Artır Butonu
- Label: "Artır"
- Her tıklamada sayaç değeri +1 artar
- Ardışık tıklamalar arası minimum gecikme yok (hızlı tıklama desteklenir)
- Başarı durumu: sayaç güncellenir, geçmişe eklenir

### 4.3 Azalt Butonu
- Label: "Azalt"
- Her tıklamada sayaç değeri -1 azalır
- Mevcut değer 0 ise negatif değere geçer
- Başarı durumu: sayaç güncellenir, geçmişe eklenir

### 4.4 Sıfırla Butonu
- Label: "Sıfırla"
- Sayaç değerini 0'a ayarlar
- Onay gerektirmez (hızlı işlem)
- Başarı durumu: sayaç 0 olur, geçmişe "Sıfırlandı" olarak eklenir

### 4.5 Değişiklik Geçmişi
- Son 10 değişiklik listelenir (en yenisi üstte)
- Her kayıt şunları içerir:
  - İşlem tipi: "Arttırıldı (+N)", "Azaltıldı (-N)", "Sıfırlandı"
  - Timestamp: GG.AA.YYYY SS:DD:SN formatında
  - Önceki değer → Yeni değer
- localStorage'da saklanır, sayfa yenilendiğinde korunur
- Boş durumda: "Henüz işlem yapılmadı" mesajı gösterilir

### 4.6 Dark Mode Toggle
- Toggle butonu sağ üst köşede
- İkon: güneş (açık tema) / ay (karanlık tema)
- Seçim localStorage'da saklanır
- Sistem tercihine göre başlangıç teması belirlenir (prefers-color-scheme)
- Geçiş animasyonlu olur (300ms fade)

## 5. Veri Modeli

### HistoryEntry
```typescript
interface HistoryEntry {
  id: string;          // UUID
  type: 'increment' | 'decrement' | 'reset';
  previousValue: number;
  newValue: number;
  timestamp: string;   // ISO 8601 formatında
}
```

### AppState (localStorage key: "sayac-state")
```typescript
interface AppState {
  count: number;
  history: HistoryEntry[];
  theme: 'light' | 'dark' | 'system';
}
```

### 6.2 Spacing & Components

**Spacing Scale:** 4/8/12/16/24/32/48/64 px
**Border Radius:** sm=4px, md=8px, lg=12px, xl=16px, full=9999px

**Kart Pattern:**
- Beyaz arka plan, md shadow, lg border-radius
- Padding: 24px
- İçerik: ortalanmış

### 7. Non-Functional Requirements

### 7.1 Performans
- İlk yükleme (LCP): < 1.5 saniye
- Sayfa geçişi: yok (SPA)
- Bundle size hedefi: < 100KB gzipped
- TTI (Time to Interactive): < 2 saniye

### 7.2 Erişilebilirlik (WCAG 2.1 AA)
- Tüm butonlar keyboard navigable (Tab, Enter, Space)
- ARIA labels tüm interactive elementlerde
- Focus ring visible (outline-offset: 2px, primary color)
- Kontrast oranı: metin >= 4.5:1, büyük metin >= 3:1
- Touch hedefleri: minimum 44x44px
- Screen reader dostu: sırasıyla sayı ve butonlar okunur

### 7.3 Tarayıcı Desteği
- Chrome 90+, Firefox 88+, Safari 14+, Edge 90+
- iOS Safari 14+, Android Chrome 90+
- Responsive: 320px (mobil) → 1920px (desktop)

## 11. Edge Cases

- Sayaç 999999 iken artır butonu tıklandığında: uyarı göster, değer sabit kalır
- Geçmiş 10 kayıttan fazlaysa: en eski silinir, yenisi eklenir
- localStorage doluysa: eski geçmiş silinir, yeni kayıt eklenir
- Tema "system" iken sistem rengi değişirse: otomatik güncellenir
